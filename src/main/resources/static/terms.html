1. System Scope & Authorized Use

SecureRank provides secure encrypted storage, TF-IDF ranked multi-keyword search, and visual cryptographic access controls. Access is governed by role-based authorization: Data Owners upload encrypted assets, Data Consumers query encrypted indices, and Administrators oversee user registration approvals and key issuance requests.

2. Key Custody & Access Control

Data Consumers may only request decryption keys for documents with a legitimate, stated operational purpose. All key requests are logged and subject to administrative approval before decryption keys are generated and transmitted.

3. Integrity & Cryptographic Guarantees

Reconstruction of QR authentication tokens requires 2-out-of-2 visual cryptographic share stacking. Visual shares are evaluated using lossless transformation pipelines to guarantee exact bit-stream fidelity without loss of data.

4. Disclaimer

This software is provided for secure ranked cloud retrieval demonstration and research evaluation in accordance with stated architectural specifications.
