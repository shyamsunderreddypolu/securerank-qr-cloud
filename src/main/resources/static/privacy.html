Privacy Notice

Last Updated: September 2026

1. Data Architecture & Encryption

SecureRank is engineered to process encrypted cloud document storage and multi-keyword search. Files uploaded by Data Owners are encrypted using standard AES-256-CBC cipher suites before storage. Plaintext document contents are never stored unencrypted on the cloud server.

2. Search Index Vectors

Search operations evaluate TF-IDF keyword vector representations. Search queries submitted by authorized Data Consumers match against these vectors without requiring the cloud server to decrypt stored documents.

3. Visual Cryptography & Key Distribution

QR code authentication tokens are split into two visual cryptographic shares: one stored in encrypted form on the server, and one retained by the client. Document decryption requires an approved Secret Decryption Key managed by the Private Key Generator (PKG) / Administrator role.

4. User Account Information

Registration requires name, email address, password hash, and designated system role (Data Owner or Data Consumer). Passwords are cryptographically hashed using BCrypt. Session management uses JSON Web Tokens (JWT).

This document represents an architectural privacy specification for the SecureRank system implementation.
